# Shark Skeleton Quiz

Welcome to the Shark Skeleton Quiz! This interactive quiz is designed to help you learn about the fascinating anatomy of sharks through an engaging and educational experience.

## Project Overview

The Shark Skeleton Quiz consists of two main pages:

1. **Introduction Page**: This page provides a brief overview of the quiz, instructions on how to participate, and a button to start the quiz.
2. **Quiz Page**: This page features an interactive image of a shark skeleton. You can click on specific points of the image to answer quiz questions related to the shark's anatomy.

## Features

- Interactive quiz format with clickable points on the shark skeleton image.
- Questions related to the anatomy of sharks.
- A counter to track the number of questions answered.
- A congratulatory message upon completing the quiz.

## Getting Started

To get started with the Shark Skeleton Quiz, follow these steps:

1. **Clone the Repository**: 
   ```bash
   git clone https://github.com/yourusername/shark-skeleton-quiz.git
   ```

2. **Navigate to the Project Directory**:
   ```bash
   cd shark-skeleton-quiz
   ```

3. **Install Dependencies**:
   Make sure you have Node.js installed, then run:
   ```bash
   npm install
   ```

4. **Build the Project**:
   Use the following command to build the project:
   ```bash
   npm run build
   ```

5. **Serve the Project**:
   You can serve the project locally using:
   ```bash
   npm start
   ```

6. **Open in Browser**:
   Open your browser and go to `http://localhost:3000` to access the quiz.

## Usage

- Start on the introduction page to learn about the quiz.
- Click the button to navigate to the quiz page.
- Interact with the shark skeleton image by clicking on the points to answer questions.
- Keep track of your progress with the question counter.
- Enjoy the quiz and learn more about shark anatomy!
